# bakery-sales-management-laravel
Laravel-based bakery sales management website designed for product, inventory, and sales control, featuring card-style UI, sales tables, and partial Ajax-based updates.
매장 운영에 필요한 판매, 재고, 제품 관리를 한 화면에서 처리할 수 있도록 구현한 베이커리 판매관리 웹사이트입니다. 카드형 제품 UI와 매출 테이블을 결합해 빠른 조회와 입력이 가능하도록 구성했습니다.
